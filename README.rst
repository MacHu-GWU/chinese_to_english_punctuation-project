Install
------------------------------------------------------------------------------

``chinese_to_english_punctuation`` is released on PyPI, so all you need is to:

.. code-block:: console

    $ pip install chinese-to-english-punctuation

To upgrade to latest version:

.. code-block:: console

    $ pip install --upgrade chinese-to-english-punctuation
